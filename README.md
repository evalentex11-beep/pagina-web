# CISET - Página web local

Sitio web institucional para CISET con oferta educativa, modelo académico, testimonios, carrusel de imágenes y formulario de contacto.

## Archivos principales

- `index.html`: estructura de la página.
- `styles.css`: estilos visuales y diseño responsive.
- `app.js`: carrusel de testimonios.
- `assets/`: imágenes de marca y testimonios.

Para visualizar la página, abre `index.html` en el navegador.
